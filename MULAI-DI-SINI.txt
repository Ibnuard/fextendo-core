FEXTendo Patch 1.3.0

1. Salin folder switch dari paket ini ke root microSD.
2. Buka FEXTendo Patch melalui hbmenu.
3. Pilih loader Standard / sys-clk atau HOC / official defaults.
   Standard adalah pilihan awal: tidak memasang HOC dan tidak mengubah sys-clk.
   Instalasi lama mempertahankan pilihan loader-nya saat aplikasi dibuka kembali.
   Tekan Y atau sentuh pilihan loader untuk menggantinya.
4. Pilih Install patch, lalu konfirmasi.
5. Reboot ke Hekate > More configs > FEXTendo Patch (emuMMC).

Atmosphere yang tersedia: 1.9.5, 1.11.2 dan 1.12.0, masing-masing Standard dan HOC.
Versi Atmosphere aktif dan package3 di SD harus sama. Revisi commit ditampilkan;
revisi berbeda tidak lagi langsung memblokir versi yang didukung.
Versi Atmosphere lain tetap memerlukan paket tersendiri.
FW/HOS berbeda dari versi Atmosphere; seluruh kombinasi belum diuji di perangkat.

HOC tetap opsional, memakai default resmi 2.5.1 di entry FEXTendo saja.
Standard mempertahankan dukungan fxtmem-v1/fxtauto-v1 tanpa kode HOC.
Kernel dan loader HOC lama tidak diubah. Paket 1.9.5 dan Standard 1.12.0 perlu tes boot/gameplay.
Installed berarti berkas terpasang; aktivasi memerlukan reboot.
Setelah update Atmosphere: boot CFW biasa dulu, buka installer, pasang paket yang
cocok, lalu boot ulang melalui entry FEXTendo Patch.

Kontrol: A pilih, B kembali/batal, Y ganti loader, + keluar, X bantuan. Touch tersedia.
Jika instalasi terputus, buka aplikasi dan pilih Recover installation.
Pengaturan sys-clk, HOC global, boot utama Hekate, dan folder game tidak diubah.

Check update memakai Ibnuard/fextendo-core untuk aplikasi dan paket boot.
Jika NRO baru tersedia: pilih Update app, tunggu selesai, keluar lalu buka lagi.
Update aplikasi tidak mengganti patch boot; untuk itu tetap pilih Install patch
kemudian reboot melalui Hekate.
Pengguna NRO sebelum 1.3.0 perlu menyalin NRO ini sekali untuk mendapat updater.
Jika update terputus dan NRO utama hilang, buka file .recovery.nro di folder yang
sama sekali untuk pemulihan, kemudian buka lagi aplikasi utamanya.
Download: https://github.com/Ibnuard/fextendo-core/releases/latest
Paket lokal berupa folder siap salin, tanpa ZIP.
